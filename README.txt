SISTEMA DE ESTOQUE - DEMONSTRAÇÃO

Arquivos:
- index.html
- styles.css
- script.js

Como usar:
1. Extraia a pasta ou o arquivo ZIP.
2. Abra o arquivo index.html no navegador.
3. Na tela de login, use qualquer usuário e senha.

Recursos incluídos:
- Tela de login
- Dashboard com abas Produtos, Compras e Estoque
- Busca nas tabelas
- Cadastro, edição e exclusão de registros
- Dados salvos no navegador com localStorage
- Layout inspirado nas imagens enviadas

Observação:
Este projeto é front-end e funciona como protótipo funcional. Se quiser, a próxima etapa pode ser transformar em sistema com banco de dados e login real.
